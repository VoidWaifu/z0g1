## Описание

**Зоги** — Telegram-бот, предоставляющий интерфейс для управления файлами, хранящимися в Telegram.

Telegram позволяет хранить файлы без ограничений по общему объёму (до 2 ГБ на файл, до 4 ГБ для Premium-пользователей). Зоги добавляет функциональность файлового менеджера: папки, переименование, перемещение. Взаимодействие осуществляется через Telegram Mini App.

## Приватность

*   Файлы остаются на серверах Telegram. Бот не скачивает и не анализирует содержимое загружаемых файлов.
*   На сервере хранятся: Telegram ID пользователя, названия файлов, размер файлов, дата загрузки.
*   Бот запрашивает минимально необходимый набор прав.

## Функции

*   Создание папок.
*   Переименование файлов и папок.
*   Перемещение файлов между папками.
*   Скачивание файлов.
*   Веб-интерфейс через Telegram Mini App.
