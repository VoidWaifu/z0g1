## 📦 Что такое Зоги?

**Зоги** — это полностью бесплатный Telegram-бот, который превращает бездонное хранилище Telegram в удобный облачный диск.

Telegram позволяет хранить файлы без ограничений по общему объёму (до 2 ГБ на файл, до 4 ГБ для Premium-пользователей). Звучит как идеальный облачный сервис, верно? Но есть нюанс: Telegram — мессенджер, а не файловый менеджер. Отыскать нужный документ в бесконечной ленте чатов — то ещё приключение.

**Зоги решает эту проблему.** Он оборачивает телеграм-хранилище в привычный интерфейс проводника: папки, переименование, перемещение — всё это прямо внутри Telegram Mini App.

## 🔐 Приватность превыше всего

Мы следуем философии приватности Telegram.

*   **Твои файлы никогда не покидают серверы Telegram.** Зоги не скачивает, не читает и не анализирует содержимое твоих загрузок.
*   **Минимум данных на сервере.** Всё, что мы храним о тебе — это твой Telegram ID, названия файлов, их размер и дата загрузки. Только метаданные для навигации. Ничего лишнего.
*   **Никаких лишних доступов.** Бот запрашивает только необходимый минимум прав.

Ты сохраняешь полный контроль над своими данными.

## ✨ Возможности

*   🗂 **Создание папок** — Структурируй файлы как тебе удобно.
*   ✏️ **Переименование** — Давай файлам и папкам осмысленные имена.
*   📁 **Перемещение** — Наводи порядок, раскидывая файлы по нужным директориям.
*   ⬇️ **Скачивание** — Забирай то, что нужно, в пару нажатий.
*   🎨 **Mini App** — Всё взаимодействие происходит через красивый и отзывчивый веб-интерфейс прямо в Telegram.
